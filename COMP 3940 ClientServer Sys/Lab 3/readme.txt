Upload Server
-------------

Compile:
    cd Server
    javac *.java

Run:
    java UploadServer

Use:
    1. Open http://localhost:8082/ in a browser to see the upload form.
    2. Enter a caption, pick a date, choose a file and press Submit.
    3. The file is saved as uploads/<caption>_<date>_<filename> and the server
       returns an alphabetically sorted HTML listing of the uploads folder.
